# 일정 캘린더

React + Vite와 일반 CSS로 만든 개인 프로젝트 일정 관리 앱입니다. 기본 일정은 2026년 10월 22일~11월 4일의 14개 작업입니다. 서버나 유료 서비스는 필요하지 않습니다.

## 로컬 실행

Node.js 22 이상과 npm을 사용합니다.

```bash
npm ci
npm run dev
```

터미널에 표시된 주소로 접속하세요. 클라우드에서 기본 npm 캐시에 쓰기 권한이 없다면 `npm ci --cache /workspace/.npm-cache`를 사용하세요.

```bash
npm run build
npm run preview
```

프로덕션 결과물은 `dist/`에 생성됩니다.

## 기능과 저장

- 큰 월간 캘린더, 이전·다음 달 이동, 오늘로 이동
- 날짜 선택 후 같은 화면에서 일정 추가·수정·삭제
- 작업 이름 클릭 시 오른쪽 상세 화면에서 수정·삭제·완료 상태 변경
- 전체 진행률, 남은 작업, 오늘의 미완료 작업 수
- 오늘 일정과 다음 일정 안내, 날짜순 전체 일정
- 일정 추가·수정·삭제, 완료 상태 변경, 검색과 완료 상태 필터
- 일정과 완료 상태를 브라우저 localStorage의 `flatpoint-planner-v1`에 자동 저장

오늘 날짜는 사용자 기기의 현지 날짜를 따릅니다. 데이터는 브라우저·사이트 주소별로 저장되며 다른 기기로 동기화되지 않습니다. 브라우저 데이터를 삭제하면 기록도 사라집니다. 저장이 불가능한 환경에서는 화면에 안내합니다. 초기 일정의 날짜를 지나면 미완료 작업은 ‘기한 지남’으로 표시합니다.

## Netlify 배포

1. 이 프로젝트를 GitHub 저장소에 올립니다.
2. Netlify에서 **Add new project → Import an existing project**로 해당 저장소를 연결합니다.
3. 빌드 명령 `npm run build`, 게시 디렉터리 `dist`를 사용합니다. `netlify.toml`에 이미 설정되어 있습니다. 환경 변수나 API 키는 필요하지 않습니다.
4. 배포 후 사이트에 접속합니다.

수동 배포는 로컬에서 `npm ci && npm run build` 후 `dist` 폴더를 Netlify에 업로드하면 됩니다. `public/_redirects`가 빌드 시 `dist/_redirects`로 복사되어 모든 경로를 `index.html`로 연결하므로 하위 경로에서 새로고침해도 앱이 열립니다.

## 구조

```text
src/App.jsx                 대시보드, 상태 관리, localStorage
src/components/Calendar.jsx 월간 캘린더와 날짜별 작업
src/components/TaskForm.jsx 일정 추가·수정 모달
src/components/TaskRow.jsx  일정 행과 작업 버튼
src/data.js                 기본 일정, 날짜 및 데이터 유효성 검사
src/styles.css              반응형 스타일
public/_redirects           Netlify SPA 라우팅
netlify.toml                Netlify 빌드 설정
```

글꼴은 Pretendard를 사용하며 public/fonts에 폰트와 SIL OFL 라이선스를 포함합니다. 외부 글꼴 서버 연결 없이 표시됩니다.

## GitHub Pages 배포

현재 공개 주소: https://10ne2.github.io/plan/

`npm run build -- --base=/plan/`으로 빌드한 뒤 `dist` 내용을 `gh-pages` 브랜치 루트에 배포합니다. `.nojekyll` 빈 파일을 포함하고, 하위 경로 새로고침 지원이 필요하면 `index.html`을 `404.html`로 복사합니다. GitHub Settings → Pages에서 `gh-pages` 브랜치의 `/ (root)`를 선택합니다. 배포 시 같은 주소의 localStorage 데이터는 유지됩니다.

오른쪽 일정 추가 폼에서 이름과 날짜를 입력해 바로 등록할 수 있습니다. 날짜 선택으로 폼 날짜를 바꿀 수 있으며, 추가 후 입력란이 비워져 연속 등록할 수 있습니다.

일정을 선택하지 않으면 오른쪽에 일정 추가 폼이 표시됩니다. 일정을 클릭하면 같은 위치에 상세 화면이 표시되며, 날짜 선택으로 추가 폼으로 돌아갑니다. 달력의 일정 제목은 한 줄로 표시하고 넘치면 말줄임표로 표시합니다. 마우스를 올리거나 상세 화면을 열면 전체 제목을 확인할 수 있습니다.

기본 본문과 입력 글자 크기는 10pt입니다. 오늘 일정 이름과 완료 상태는 상단 대시보드에서 확인하며, 클릭하면 상세가 열립니다.

배포 후 새로고침 시점: 저장소 Actions에서 최신 gh-pages 커밋에 해당하는 `pages build and deployment` 실행이 초록색 성공 표시로 바뀌면 공개 페이지를 새로고침합니다. 진행 중이거나 대기 중일 때는 이전 버전이 보일 수 있습니다.

상단 오늘 일정과 일정 상세의 체크박스로 완료 상태를 바로 변경할 수 있습니다. 대시보드에는 전체 진행률과 오늘 날짜의 일정만 기준으로 한 오늘 진행률이 표시됩니다. 오늘 일정이 없으면 오늘 진행률은 0%입니다.

오른쪽 입력 폼 아래 날짜별 메모는 클릭하여 편집하고 바깥을 클릭하면 읽기 상태로 표시됩니다. 줄바꿈을 지원하며, 입력 내용은 별도 localStorage 키 `flatpoint-planner-memos-v2`에 자동 저장됩니다. 선택한 날짜별로 따로 저장되며, 일정 선택이나 날짜 이동으로 지워지지 않습니다. 기존 공용 메모는 업데이트 후 처음 열린 날짜로 옮기고 원래 저장 키도 보존합니다.

메모는 각 줄 앞에 `·`를 표시하는 목록 형식입니다. Enter와 여러 줄 붙여넣기에 자동으로 머리말이 붙으며, 저장 시에는 본문과 줄바꿈만 보관하여 머리말이 중복되지 않습니다.

데스크톱에서 상세 입력칸을 세로로 늘리면 일정이 있는 주의 달력 행 높이만 함께 늘어납니다. 일정이 없는 주는 기본 높이를 유지합니다. 일정 삭제는 확인창 없이 즉시 실행되며 하단에 각 삭제 건별로 10초 동안 복구 버튼이 표시됩니다. 복구 시 날짜와 완료 상태도 보존됩니다. 복구 대기는 현재 화면에서만 유지되며 새로고침 시 종료됩니다.

메모 편집 시 입력한 줄 수와 자동 줄바꿈에 맞춰 높이가 자동 조절됩니다. 편집 중에는 테두리가 보이고, 바깥을 클릭해 읽기 상태가 되면 테두리가 사라집니다.
